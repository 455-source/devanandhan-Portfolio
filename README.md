# Devanandhan O S — Personal Portfolio

A personal portfolio website built to showcase my journey as a Computer Science student, my technical skills, academic projects, and interests.

Built using Python, Flask, HTML and CSS.


## About the Project

This portfolio was created as a personal project while exploring web development.

It showcases:

- My academic background
- Technical skills
- Academic projects
- Areas of interest
- GitHub and LinkedIn profiles
- Contact information

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Git
- GitHub


##  Features

- Responsive portfolio website
- Dark modern interface
- Personal introduction
- Education section
- Technical skills section
- Interactive curved project showcase
- Project descriptions
- GitHub integration
- LinkedIn integration
- Gmail contact link
- Responsive mobile layout
